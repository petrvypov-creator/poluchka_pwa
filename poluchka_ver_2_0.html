⚙️ Главное меню
📘 Руководство «Получка»

Версия: PWA v2.3
Разработчик: Выпов Петр Викторович ☭

1. Установка на iPhone (Офлайн)

  1. Откройте файл в браузере Safari.
  2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх).
  3. Выберите «На экран "Домой"».
  4. Готово! Приложение работает без интернета.

2. Расчет зарплаты

  • Вкладка «Смена» автоматически определяет День/Ночь по вашему циклу.
  • Включите галочку «🎈 Праздник» и выберите режим оплаты (вся смена, до 00:00 или после 00:00).
  • Для Фиксы укажите галочку «💰 Фиксированная выплата» (КТУ игнорируется).

3. График смен

  • На вкладке «График» задайте ваш цикл (Например: Д, Н, В, В).
  • Зелёный индикатор (светодиод) в ячейке означает, что смена сохранена.
  • Клик по любой ячейке открывает окно редактирования на этот день.

4. Пасхалки 🎮

  • Нажмите на «Доход за месяц» на Дашборде 4 раза для открытия Тетриса.
  • Нажмите 5 раз — для режима Миллионера 🤑.

5. Бэкап и Восстановление

Чтобы перенести данные на другой телефон, нажмите «Сохранить резервную копию» на вкладке Бэкап. Файл будет сохранен в «Файлы» (Files) вашего телефона. Затем передайте его и загрузите кнопкой «Восстановить».
